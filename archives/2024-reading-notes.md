# 2024 年阅读笔记

今年读了不少好书，记录一下印象深刻的几本。

## 《黑客与画家》

作者：Paul Graham

这本书让我重新思考了编程的本质。编程不仅仅是写代码，更是一种创造性的活动。就像画家创作画作一样，程序员也在创造自己的作品。

### 核心观点

- 编程语言的选择很重要
- 好的设计是简单的设计
- 创业公司的优势在于灵活性

### 我的思考

在实际工作中，我发现确实如此。选择合适的工具和语言，能让开发效率提升数倍。

## 《深入理解计算机系统》

作者：Randal E. Bryant, David R. O'Hallaron

这本书帮我建立了对计算机系统的完整认知。

### 重点章节

1. **程序的机器级表示** - 理解汇编语言
2. **存储器层次结构** - 缓存的工作原理
3. **虚拟内存** - 操作系统的内存管理

```c
// 一个简单的内存分配示例
void *malloc(size_t size) {
    // 从堆中分配内存
    void *ptr = sbrk(size);
    return ptr;
}
```

## 《人月神话》

作者：Frederick P. Brooks Jr.

经典的软件工程著作，虽然写于几十年前，但很多观点至今仍然适用。

> 向进度落后的项目中增加人手，只会使进度更加落后。

这句话在现实中被反复验证。
